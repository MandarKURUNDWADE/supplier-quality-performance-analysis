# Supplier / Vendor Quality & Performance Analysis

## Overview

An end-to-end retail and wholesale analytics project that combines
purchasing, sales, inventory, and vendor data to identify opportunities
to improve profitability, reduce unsold stock, and support better
supplier decisions.

## Tools

Python, Pandas, SQL, SQLite, SQLAlchemy, Jupyter Notebook, SciPy, and
Power BI.

## Workflow

1.  Import six source files into SQLite.
2.  Clean, aggregate, and join data using SQL and Python.
3.  Perform exploratory data analysis and statistical testing.
4.  Build a Power BI dashboard to report KPIs and business insights.

## Key Findings

-   Unsold inventory tied up approximately **\$2.7 million** in capital.
-   The top 10 vendors represented approximately **65.69%** of total
    purchases.
-   Bulk purchasing showed an approximate **72% reduction** in unit cost
    from small to large purchase volumes.
-   **198 brands** were identified for potential pricing or promotional
    review due to low sales and high margins.

## Recommendations

-   Review pricing and promotions for low-sales, high-margin brands.
-   Use bulk purchasing strategically while avoiding excess inventory.
-   Improve slow-moving inventory management.
-   Monitor vendor concentration and evaluate supplier performance using
    both sales and profit margin.

## Business Value

The project demonstrates how Python, SQL, statistical analysis, and
Power BI can turn raw operational data into actionable insights for
inventory planning, purchasing strategy, and vendor performance
management.
